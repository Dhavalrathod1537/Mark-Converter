🎓 Marks Converter

A simple and responsive web application that helps students convert CGPA, SPI, marks and grades into percentage (and back) using different university formulas.

🔗 **Live Demo:** https://dhavalrathod1537.github.io/YOUR-REPO

✨ Features

- CGPA to Percentage
- Percentage to CGPA
- SPI to Percentage
- Marks to Percentage
- Percentage to Grade
- University-wise formula selection (Nirma, Parul, GTU, IIT Bombay, Mumbai University and more)
- Result reactions with emoji and message based on performance
- Conversion history
- Mobile friendly design

🛠️ Built With

- HTML5
- CSS3
- JavaScript

🚀 How to Use

1. Open the live demo link.
2. Select your university.
3. Enter your CGPA, SPI or marks.
4. Click Convert to see the result.

💻 Run Locally

```bash
git clone https://github.com/Dhavalrathod1537/YOUR-REPO.git
cd YOUR-REPO
```
Then open `index.html` in your browser.

⚠️ Disclaimer

Results are approximate. Conversion formulas differ between universities and may change over time. Always verify with your official marksheet or university circular.
